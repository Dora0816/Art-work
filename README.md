# 人生，是一條正在延伸的路

這是一份以人生歷程為主題的互動式數位繪本。使用者可以點選人生階段，閱讀各階段的文字與反思問題，並在最後選擇一個詞，作為此刻的生命註記。

## 作品概念

人生像一條不斷延伸的道路，從童年的懵懂、青春的探索，到成年後的選擇與回望。作品以抽象時間軸呈現生命不同階段，邀請觀眾把自己的經驗投射進故事。

青春篇以時代少年團的歌曲《少年時代》作為個人青春記憶的引子，談音樂、喜歡的人事物，以及它們如何成為成長過程中的註腳。網站沒有收錄歌曲完整歌詞或音訊。

## 互動內容

- 點選八個人生階段，切換故事文字與反思問題
- 使用上一段／下一段按鈕瀏覽
- 在結尾選擇「探索、勇氣、珍惜、改變、期待」
- 支援手機與桌面瀏覽

## GitHub Pages 發布方式

1. 開啟此 repository 的 **Settings**。
2. 在左側選擇 **Pages**。
3. 在 **Build and deployment** 中，Source 選擇 **Deploy from a branch**。
4. Branch 選擇 **main**，資料夾選擇 **/(root)**，按下 **Save**。
5. 等待 GitHub Pages 完成部署。

網站網址通常會是：

https://Dora0816.github.io/Art-work/

## 使用提醒

此網站設定為公開 repository，請勿加入住址、電話、車牌、個人證件或其他不想公開的個人資料。若未來加入照片，請先確認照片中的人物同意公開。
